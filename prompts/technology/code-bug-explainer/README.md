# Code Bug Explainer & Fixer

A structured, chain-of-thought prompt designed to help beginner programmers debug code errors, understand underlying programming concepts, and learn best practices.

## Overview
When learning to code, hitting an error message can be frustrating. Standard AI prompts often just spit out the answer without explaining *why* the bug occurred. This prompt forces the AI to support you and walk through a logical, step-by-step diagnostic process before providing the corrected code.

## Framework & Technique Used
- **Structure:** C-A-R-E-S 
- **Technique:** Chain-of-Thought 

## How to Use
1. Copy the prompt text from `prompt.md`.
2. Replace the **Input Data** section at the bottom with your specific programming language, error message, and broken code.
3. Paste it into your LLM of choice to receive a clear, educational debugging breakdown.
